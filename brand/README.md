# 브랜드 에셋

디자이너가 제작한 로고·파비콘 원본 보관 폴더입니다. **여기 있는 파일은 이미 가공된
최종본이며, Illustrator 원본으로 다시 내보내 덮어쓰면 안 됩니다**(아래 "가공 내역" 참고).

## 파일별 실제 사용처

| 파일 | 사용처 | 비고 |
|---|---|---|
| `wecarry-logo.svg` | `components/BrandLogo.tsx`에 **인라인으로 복사됨** | 랜딩 헤더. 이 파일은 디자인 소스이고, 실제 렌더링은 컴포넌트가 함 — **로고가 바뀌면 두 곳을 같이 갱신할 것** |
| `wecarry-favicon-dark.svg` | **미사용(보관)** | 검정 배경 + 노랑 W. 아래 "파비콘 색상" 참고 |

배포되는 파비콘은 이 폴더가 아니라 Next.js App Router 파일 컨벤션 위치에 있습니다
(중복 보관하면 한쪽만 고치는 사고가 나므로 일부러 사본을 두지 않았습니다):

| 경로 | 원래 파일명 | 용도 |
|---|---|---|
| `app/icon.svg` | `wecarry-favicon.svg` | 기본 파비콘 (노랑 배경 + 검정 W) |
| `app/apple-icon.png` | `apple-touch-icon.png` | iOS 홈화면 아이콘 (180×180) |

Next.js가 이 두 파일을 보고 `<link rel="icon">` / `<link rel="apple-touch-icon">`을
자동으로 생성하므로 `metadata.icons`를 따로 적을 필요가 없습니다.

## 가공 내역 (원본으로 덮어쓰면 재발하는 문제들)

| # | 원본 문제 | 처리 |
|---|---|---|
| 1 | 워드마크 viewBox가 `0 0 1000 200`인데 실제 아트웍은 969×139만 차지 → `height:28px`를 줘도 **로고가 19px로 렌더링됨** | viewBox를 아트웍 bbox+여백으로 크롭 (`viewBox="9 25 982 151"`) |
| 2 | 워드마크에 길이 0짜리 흰색 `<line>` 잔여물(Illustrator 내보내기 찌꺼기) | 제거 |
| 3 | 워드마크 색상이 고정값이라 다크 배경에서 안 보임 | 루트에 `fill="currentColor"` → 부모 `color` 상속 |
| 4 | apple-touch-icon에 라운드 코너가 있어 iOS 자체 마스킹과 이중으로 깎임 | 라운드 제거한 정사각으로 생성 |

## 색상 처리 방식이 서로 다름 — 헷갈리지 말 것

- **워드마크**: `fill="currentColor"` — 부모의 `color`를 상속받습니다. 그래서 반드시
  **인라인 SVG**여야 하고, `<img src>`나 `next/image`로 참조하면 색상이 검정으로
  고정되어 다크 배경에서 안 보입니다.
- **파비콘**: 배경색이 채워진 디자인이라 `currentColor` 처리가 없습니다. 그대로 씁니다.

## 워드마크 종횡비 6.50 : 1

높이 28px → 폭 182px. **width를 고정하지 말고 높이만 지정**해야 비율이 유지됩니다
(`.landing-brand-logo` 참고: 데스크탑 28px / 모바일 24px).

가로로 긴 로고라 모바일 헤더 여유가 좁습니다 — **헤더에 요소를 추가하면 360px에서
가로 스크롤이 생기지 않는지 반드시 재확인**할 것. 또 높이를 20px 이하로 줄이면 로고
안의 한글 "위캐리 운송" 판독이 어려워지므로, 더 줄여야 하는 상황이면 임의로 줄이지 말고
확인을 받을 것.

## 파비콘 색상 — 기본은 노랑

`app/icon.svg`(노랑 배경)를 기본으로 씁니다. 브라우저 탭 영역이 밝든 어둡든 노랑이
눈에 띄어 다크모드에서도 묻히지 않기 때문입니다. `wecarry-favicon-dark.svg`(검정 배경)는
대안으로 보관만 하며, **임의로 교체하지 말 것**(교체가 낫다고 판단되면 먼저 보고).

## 브랜드 옐로 `#ffd833`

`app/globals.css`에 `--brand-yellow` 변수로 등록만 되어 있고 **아직 어디에도 적용되지
않았습니다.** 이 색을 사이트 전반 액센트로 쓸지는 미결정 상태이므로, 기존 UI 색상을
이 값으로 바꾸기 전에 확인받을 것.
