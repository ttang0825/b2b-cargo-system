내려앉아 **세로 중심이 14px 어긋났다**(713 vs 727). 지금은 헤더로 옮겨져 해당 없지만,
이 컴포넌트를 다시 배치할 때 **바깥·안쪽 두 겹**이라는 것을 기억할 것.

**═══ ⑤ 🔴 아이폰 안내의 점 세 개는 `···` 이지 `⋯` 이 아니다 ═══**
사용자 지적: *"「...」을 먼저 선택하고 공유 버튼을 누르고 「홈 화면에 추가」를 눌러야 한다."*
맞다 — **최신 사파리는 아래 막대가 접혀 있어 공유 단추가 바로 보이지 않는다.**
```
  전  1) 아래쪽 공유 단추를 누릅니다
  후  1) 주소창 오른쪽 ···(더보기)를 누른 뒤 공유를 누릅니다
         └ 공유가 아래에 보이면 바로 눌러도 됩니다
      2) 목록을 내려 「홈 화면에 추가」
      3) 오른쪽 위 「추가」
```
🔴 **`⋯`(U+22EF, MIDNLINE HORIZONTAL ELLIPSIS)로 되돌리지 말 것** — 서체에 없으면
**네모 상자로 보인다**(검증 환경에서 실제로 그렇게 나왔다). 지금 것은
**가운뎃점(U+00B7) 3개**라 어느 서체에나 있고 사파리 단추 모양과도 같다.
🔴 **3단계 문구를 줄이지 말 것**(⑪ 축약에서도 제외했다) — **실제 아이폰 메뉴에 적힌
말**이라 바꾸면 화주가 그 메뉴를 못 찾는다.

**═══ ⑥ 🔴 브라우저가 다르면 로그인을 넘길 수 없다 — 세 번 물어도 답은 같다 ═══**
사용자 질문: *"카톡에서 로그인한 상태에서 기본브라우저로 넘어갈 때 다시 계정,비번
입력창으로 가는데 이게 맞는건가?"* → **맞고 피할 방법이 없다.**
카카오톡 안 브라우저와 사파리/크롬은 **완전히 다른 브라우저**라 쿠키·저장 공간을 서로
못 본다. 🔴 **넘기려면 로그인 상태를 주소에 실어야 하는데 그 주소가 새면 계정이 새는
것이다 — 「넘길 수 있는 방법이 있나」를 다시 찾지 말 것.**
🟢 코드로 고치는 대신 **안내창에 미리 적어** 헛걸음을 막았다.

**═══ ⑦ 🔴 안내창 가로 끌림 — 원인은 내가 넣은 `nowrap` 이었다 ═══**
리뷰 2라운드: *"홈화면추가 설명 팝업은 가로가 길어져서 옆으로 드레그하게 되어 있는데
불편하고 이상하다."*
🔴 **원인은 내용 폭이 아니라 상속이다.** 두 단추를 한 줄에 두려고 넣었던
`.landing-login-actions > div { white-space: nowrap !important }` 가, **같은 상자 안에서
열리는 안내창까지 상속**되어 문장이 한 줄로 쭉 늘어나 있었다(안내창은 버튼의 형제로
그 래퍼 안에 그려진다).
🟢 그 규칙을 없애고 **안내창이 자기 글자 속성을 스스로 선언**하게 했다 —
`whiteSpace: "normal"` · `overflowX: "hidden"` · `overflowWrap: "anywhere"`.
🔴 **`.landing-login-actions` 에 `white-space: nowrap` 을 다시 넣지 말 것**(주석에도
못박아 뒀다). ⚠️ **65차 ⑤ · 66차 ⑯-3 과 같은 자리다** — 그때는 색과 정렬이었고
이번엔 줄바꿈이다. **모달은 색·정렬·줄바꿈 셋을 자기가 선언해야 한다.**

**═══ ⑧ 🔴 아이폰에서 한 번에 추가하는 방법은 없다 ═══**
리뷰 2라운드 질문: *"아이폰에서 홈화면 추가 과정을 한번에 간단하게 해줄수 있는 방법은
없나?"* → **애플이 그런 통로를 제공하지 않는다.** 안드로이드·데스크탑 크롬에는
`beforeinstallprompt` 가 있어 눌러서 바로 설치되지만 **아이폰 사파리에는 그 신호 자체가
없다**(PWA 차수 ④ 가 「죽은 버튼을 만들지 않았다」고 적어둔 것과 같은 사실이다).
🔴 **줄일 수 있는 것은 안내의 정확성뿐이라 ⑤ 를 실제 순서로 고친 것이 답이다.**

**═══ ⑨ 🔴 홈 화면 앱 창은 사파리와 저장 공간이 완전히 분리된 칸이다 ═══**
리뷰 3라운드: *"홈화면 추가 안한 상태에서 로그인하고 그 이후 홈화면을 추가해서 접속하면
로그아웃상태에서 시작하는데 로그인 상태에서 이어서 진행할 수 없나? 아이디 저장 기록도
깨지는 것 같다."*
🔴 **둘 다 맞고 세션 자체는 넘길 수 없다** — 아이폰은 홈 화면 앱 창을 별도 저장 칸으로
다룬다(「아이디 저장」도 그 칸에 따로 잡힌다). ⚠️ **안드로이드는 해당 없다** — 크롬과
저장 공간을 같이 쓴다.
🟢 **그런데 칸막이를 넘어가는 것이 하나 있다 — 비밀번호 저장소(키체인)는 기기 전체가
공유한다.** 그리고 **로그인 칸에 그 힌트가 하나도 안 붙어 있었다.**
```
                        그전                    지금
  포털 아이디      autoComplete만          + name="username" · id
  포털 비밀번호    🔴 **아무것도 없음**     autoComplete="current-password" · name · id
  관리자 이메일    🔴 **아무것도 없음**     autoComplete="username" · name · id
  관리자 비밀번호  🔴 **아무것도 없음**     autoComplete="current-password" · name · id
```
🔴 **비밀번호 변경 화면 2곳(`customer/change-password` · `admin/my-account`)에는
`new-password` 를 넣었다** — `current-password` 를 그대로 쓰면 **새 비밀번호 칸에 옛
비밀번호가 채워진다.** `PasswordInput` 에 **기본값을 두지 않은 것이 그래서다.**
🔴 **`PasswordInput` 의 `autoComplete` 에 기본값을 만들지 말 것** — 로그인과 변경
화면의 올바른 값이 서로 다르다.

**═══ ⑩ 안내창 문구 축약 (리뷰 3라운드) ═══**
*"홈화면 추가 설명창의 내용들이 너무 길다. 좀 더 간략하게 줄여줘."* 다섯 곳을 줄였다 —
머리말 3갈래 · 아이폰 회색 안내(3문장 → 1문장) · 카톡 폴백 · 카톡 재로그인 · 1단계 부기.
🟢 **곁들여 중복 하나를 없앴다** — 아이폰 회색 안내를 **`{ios && !inApp}`** 으로 갈랐다.
카톡 갈래에는 아래에 같은 뜻의 안내가 이미 있어 **같은 말이 두 번** 나오고 있었다.
🔴 **줄이지 않은 것 둘** — 3단계 절차 문구(위 ⑤)와, **카톡 재로그인·아이폰 저장 공간
안내의 뜻**(문장만 줄였다). 둘 다 실제 문의에서 나온 항목이라 없애면 「왜 다시
로그인하지」가 되돌아온다.
