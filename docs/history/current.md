**조용히 안 바뀐다**(에러도 경고도 없다). ② 단언에 「예상 밖의 차급명이 있으면 중단」을
넣어 막았다.

**═══ ⑤ 🔴 값을 손으로 옮기지 않았다 ═══**
엑셀에서 **프로그램으로 뽑아** SQL 을 생성하고, 생성 뒤 165행을 엑셀과 **다시 전수
대조**했다. 한 칸만 틀려도 **그 칸의 견적만** 조용히 어긋나서 한참 뒤에 발견된다.
```
  대조 4중   지시서 2-1 표 ↔ 엑셀 2_화주청구_v11 ↔ 생성 SQL ↔ 운영 DB(apply 후)
  결과       165칸 전부 불일치 0
  ×1.15 검산  v10 있는 135칸 중 어긋난 칸 = 위 ② 세 칸뿐
  보간 검산   8톤 = (5톤+/축+11톤)/2 · 15톤 = (11톤+18톤)/2 → 어긋난 칸 0
```
⚠️ **파이썬 `round(x, -3)` 을 쓰면 안 된다** — 부동소수점 때문에 `90000*1.15` 가
103499.99… 가 되어 103,000 으로 내려간다. `Decimal` + `ROUND_HALF_UP` 으로 재야
엑셀 `ROUND()` 와 같다. 이걸 모르고 처음에 「어긋난 칸 12개」라는 **거짓 ❌** 를 냈다.

로그아웃상태에서 시작하는데 로그인 상태에서 이어서 진행할 수 없나? 아이디 저장 기록도
깨지는 것 같다."*
🔴 **둘 다 맞고 세션 자체는 넘길 수 없다** — 아이폰은 홈 화면 앱 창을 별도 저장 칸으로
다룬다(「아이디 저장」도 그 칸에 따로 잡힌다). ⚠️ **안드로이드는 해당 없다** — 크롬과
저장 공간을 같이 쓴다.
🟢 **그런데 칸막이를 넘어가는 것이 하나 있다 — 비밀번호 저장소(키체인)는 기기 전체가
공유한다.** 그리고 **로그인 칸에 그 힌트가 하나도 안 붙어 있었다.**
```
                        그전                    지금
  포털 아이디      autoComplete만          + name="username" · id
  포털 비밀번호    🔴 **아무것도 없음**     autoComplete="current-password" · name · id
  관리자 이메일    🔴 **아무것도 없음**     autoComplete="username" · name · id
  관리자 비밀번호  🔴 **아무것도 없음**     autoComplete="current-password" · name · id
```
🔴 **비밀번호 변경 화면 2곳(`customer/change-password` · `admin/my-account`)에는
`new-password` 를 넣었다** — `current-password` 를 그대로 쓰면 **새 비밀번호 칸에 옛
비밀번호가 채워진다.** `PasswordInput` 에 **기본값을 두지 않은 것이 그래서다.**
🔴 **`PasswordInput` 의 `autoComplete` 에 기본값을 만들지 말 것** — 로그인과 변경
화면의 올바른 값이 서로 다르다.

**═══ ⑩ 안내창 문구 축약 (리뷰 3라운드) ═══**
*"홈화면 추가 설명창의 내용들이 너무 길다. 좀 더 간략하게 줄여줘."* 다섯 곳을 줄였다 —
머리말 3갈래 · 아이폰 회색 안내(3문장 → 1문장) · 카톡 폴백 · 카톡 재로그인 · 1단계 부기.
🟢 **곁들여 중복 하나를 없앴다** — 아이폰 회색 안내를 **`{ios && !inApp}`** 으로 갈랐다.
카톡 갈래에는 아래에 같은 뜻의 안내가 이미 있어 **같은 말이 두 번** 나오고 있었다.
🔴 **줄이지 않은 것 둘** — 3단계 절차 문구(위 ⑤)와, **카톡 재로그인·아이폰 저장 공간
안내의 뜻**(문장만 줄였다). 둘 다 실제 문의에서 나온 항목이라 없애면 「왜 다시
로그인하지」가 되돌아온다.
