# 메일 서명용 로고 (PNG)

🔴 **이 폴더의 PNG 는 저장소 코드가 참조하지 않는다 — "안 쓰이는 이미지"로 보고 지우지 말 것.**
직원들의 **메일 서명 HTML** 이 절대 URL 로 직접 가져다 쓴다. 지우거나 파일명을 바꾸면 이미
발송된 메일들의 서명 이미지가 전부 깨진다(`public/landing/service-04-moving.jpg` 와 같은 성격).

| 파일 | 크기 | 배경 | 쓰는 곳 |
|---|---|---|---|
| `wecarry-logo-400.png` | 400×72 (RGBA) | 투명 | 밝은 배경 전제. 기본값 |
| `wecarry-logo-400-white.png` | 400×72 (RGB) | 흰색 | 다크모드 대응 |

- 공개 주소: `https://wecarrylogis.co.kr/email/<파일명>`
- **표시 크기는 200×36** (2배 해상도로 만들어 레티나에서도 선명하다). `width`/`height` 를
  반드시 명시할 것 — 안 적으면 Outlook 이 원본 400px 로 그린다.

## 🔴 왜 SVG 가 아니라 PNG 인가

**메일 클라이언트는 SVG 를 못 읽는다** — Outlook(윈도우)은 지원 자체가 없고 Gmail·네이버메일은
`<img>` 안의 SVG 를 막는다. 그래서 `brand/wecarry-logo.svg` 나 `/landing/wecarry-logo.svg` 를
서명에 그대로 넣으면 깨진 이미지로 뜬다. **SVG 로 되돌리지 말 것.**

## 🔴 왜 두 벌인가

투명본은 검정 워드마크라 **다크모드 메일에서 글자가 배경에 묻힌다**(실측 확인). 흰배경본은
어디서나 보이지만 다크모드에서 흰 박스가 보인다. 어느 쪽을 쓸지는 취향이라 둘 다 둔다 —
**한쪽만 남기지 말 것.**

## 만드는 법 (로고가 바뀌면)

원본은 **`brand/wecarry-logo.svg`** 다(`/landing/wecarry-logo.svg` 가 아니다 — 그쪽은
여백이 넓은 디자인팀 원본이고 길이 0짜리 흰색 `<line>` 잔여물이 남아 있다).
Chromium 으로 400×72 캔버스(좌우 16px 여백)에 렌더링해 캡처했다. 캔버스를 두 벌이 똑같이
쓰는 이유는 서명 HTML 에서 `width` 를 하나로 유지하기 위해서다.
